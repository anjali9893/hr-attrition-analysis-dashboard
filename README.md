# HR Attrition Analysis Dashboard using Power BI

## Project Overview
This project focuses on analyzing employee attrition trends using Power BI. The objective is to understand workforce turnover patterns and identify important factors associated with employee attrition across different departments, experience levels, and age groups.

## Objectives
- Analyze employee attrition patterns.
- Understand workforce turnover trends.
- Calculate important HR performance indicators.
- Identify attrition trends across departments and employee demographics.
- Support data-driven employee retention decisions.

## Technologies Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Workflow

1. Data Collection: Work with employee demographic and performance datasets.
2. Data Cleaning: Clean and transform data using Power Query.
3. Data Modeling: Organize employee data for meaningful analysis.
4. KPI Development: Create customized DAX measures.
5. Attrition Analysis: Analyze turnover across departments, experience levels, and age groups.
6. Dashboard Development: Build an interactive HR analytics dashboard.

## Key Activities
- Ingested, cleaned, and modeled employee datasets.
- Developed customized DAX measures and KPIs.
- Calculated attrition rates dynamically.
- Analyzed attrition across departments, experience levels, and age brackets.
- Created an executive-level dashboard to communicate workforce insights.

## Business Applications
- Employee retention planning.
- Workforce management.
- Identification of attrition trends.
- Data-driven HR decision-making.
